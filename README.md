# E-Commerce Sales Analysis – Tableau

# Project Overview
This project analyzes e-commerce sales data using Tableau to explore sales trends, product performance and business performance.

# Objectives
- Analyze sales performance.
- Identify sales trends.
- Explore product performance.
- Support data-driven decision-making.

# Tools Used
- Tableau

## Business Questions

This dashboard aims to answer the following business questions:

- How are sales and profit changing over time?
- Which product categories and sub-categories contribute the most to sales?
- Which regions generate the highest sales?
- What is the overall profitability of the business?
- How does sales performance change over time?
